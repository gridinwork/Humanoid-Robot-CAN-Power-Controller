# PCB Manufacturing Files

This directory contains the manufacturing and assembly package for the MotorDriver_CAN PCB used in the Humanoid Robot CAN & Power Controller project.

## Directory structure

- `BOM/` — Bills of Materials for PCB manufacturing and assembly.
- `Assembly/` — Pick & Place / component placement files.
- `Fabrication/Gerber/` — Gerber and CAM fabrication data.
- `Fabrication/NC Drill/` — plated-hole, slot and drilling data.
- `Fabrication/Report Board Stack/` — PCB board-stack manufacturing report.

These files are provided as engineering/manufacturing documentation. Verify fabrication parameters and component availability with the selected PCB manufacturer before production.
